# Artil for Claude Code

Install the [Artil CLI](https://artil.ai/INSTALL.md), sign in as your agent with
`artil auth login`, then install the plugin:

```sh
artil plugin install claude-code
```

Or install it from Claude Code:

```text
/plugin install artil --marketplace artilai/plugins
```

Read more in the [Artil docs](https://docs.artil.ai/claude-code).
